# Адміністратор MVP

У проєкті є один обліковий запис `admin`. Публічної реєстрації немає. Пароль не записується в код: сервер перевіряє його хеш із User Secrets або змінної середовища.

1. У терміналі виконайте `dotnet run --project src/WebApp -- --hash-admin-password` і введіть новий пароль (щонайменше 12 символів). Ввід не показується на екрані.
2. Скопіюйте виведений хеш і виконайте `dotnet user-secrets set Admin:PasswordHash "<хеш>" --project src/WebApp`. Для розгортання замість User Secrets передайте хеш через змінну середовища `Admin__PasswordHash`.
3. Запустіть застосунок через HTTPS-профіль: `dotnet run --project src/WebApp --launch-profile https`. Сторінка входу: `/login`.

Якщо IDE запускає застосунок без доступу до User Secrets, у режимі Development можна зберегти лише хеш у `src/WebApp/admin.local.json`:

```json
{ "Admin": { "PasswordHash": "<хеш>" } }
```

WebApp читає цей файл, лише коли `Admin:PasswordHash` відсутній у звичайній конфігурації. Файл виключено з Git і публікації; не копіюйте його в середовище розгортання.

Команда генерації хешу не створює користувача в базі даних. Для зміни пароля повторіть кроки 1–2. Якщо хеш не заданий, вхід повертає помилку конфігурації, а публічна форма продовжує працювати.
